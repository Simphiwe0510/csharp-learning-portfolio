# Tutorial 02 — Question 2: Stock value report

Original student-authored 2025 UJ C# exercise in `Program.cs`. This console application uses parallel arrays to store two products, generates random quantities, calculates stock value and prints a report with rand currency formatting.

The simple .NET 8 project file and documentation were added for the portfolio. Input parsing is not validated and `ReadKey` requires an interactive terminal. Source is preserved as originally submitted.

Run with `dotnet run` from this directory.

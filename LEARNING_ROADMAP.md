## How I plan to verify each project

1. Confirm that its source is my completed work, not an unanswered assignment or lecturer example.
2. Inspect for student numbers, private data, secrets, and machine-specific files.
3. Retain source and solution/project files, but exclude generated `bin/`, `obj/` and `.vs/` folders.
4. Build and run where supported, and document any errors honestly.
5. Explain the purpose, concepts, input and output in each project README.

# Learning roadmap

The published exercises demonstrate progression through arrays and loops (Tutorial 02), inheritance (Formative 04 and Tutorial 06), custom exceptions (Formative 05 and Tutorial 08), files (Tutorial 09), Windows Forms (Tutorial 10) and integrated summative exercises. HourlyWorkerOOP demonstrates abstraction and pay calculations.

Next learning goals: correct the documented logic defects in separate refactored versions, add meaningful behavior tests, validate console input, use safe file parsing, and manually test the three Windows Forms interfaces. These are future improvements, not claims of completed work.

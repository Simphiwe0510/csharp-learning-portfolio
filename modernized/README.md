# Existing modernized portfolio projects

These four .NET 8 versions were already on GitHub before the archive import. Three correspond to original exercises; HourlyWorkerOOP exists only in this version in the available inputs. These are not byte-identical originals. Build each project separately with `dotnet build --configuration Release`. See the root project index and verification report.
